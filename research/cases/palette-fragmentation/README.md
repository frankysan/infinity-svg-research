# Palette-fragmented traces

Status: **identified / deferred**

Hard-classified examples in scanner v8.6 include Chaiyi Yaokong, Gud'n Troops, Shaolin Warrior Monks,
Tian Gou, Zhanshi, and Zhanshi Yisheng.

The pathology is not merely excessive colour count. The same intended regions are fragmented into many
trace boundaries and intermediate colours. Palette snapping is useful as an isolated experiment but does
not reconstruct the original vector structure.

Current preferred research direction is source-render-guided boundary reconstruction. Historical
first-party images may serve as coarse guardrails. Third-party Human Sphere images may assist matching or
review but are non-authoritative.
